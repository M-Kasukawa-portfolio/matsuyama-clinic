# MATSUYAMA CLINIC（架空・採用サイト）

Hello Mentor 課題で制作した、架空のクリニックのリクルートサイトです。
Figmaのデザインカンプに基づきコーディングしました。

## Demo

https://mkdesignworks.net/portfolio/matsuyama-clinic/index.html

## 概要

- 内容: 採用向けトップページ（静的HTML）
- 位置づけ: 学習課題（実務案件ではありません）
- 担当: コーディング（デザインは含みません）

## 使用技術

HTML5 / Sass(SCSS) / JavaScript

## この課題で扱ったこと

テキストや画像が画面幅に合わせて拡大縮小する見せ方を実装しました。
画像が多いサイトでは有効な一方、文字サイズも縮小しやすいため、
ブログやメディアなどテキスト中心のサイトには向きにくい、という点を学びました。
